# Wave Survival System

A first-person wave survival gameplay system built in Unity (C#).

## Setup

1. Clone the repository
2. Open the project in Unity 6 (6000.3.8f1 or compatible)
3. Open `SampleScene` in `Assets/Scenes`
4. Press Play

## Controls

- **WASD** — Move
- **Mouse** — Look
- **Left Click** — Shoot
- **Space** — Jump
- **E** — Interact
- **Escape** — Pause

## How to Play

Walk to the start button and press E to begin. Enemies spawn in waves — survive as long as you can. Killing enemies heals you.
